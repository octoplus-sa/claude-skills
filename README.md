# claude-skills

Claude Code skills published by Octoplus, distributed as a [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces.md).

## Install

In Claude Code, add the marketplace once:

```
/plugin marketplace add octoplus-sa/claude-skills
```

Then install any skill from it:

```
/plugin install jmp-jsl@octoplus-sa-claude-skills
```

To list available plugins or remove one:

```
/plugin marketplace list
/plugin uninstall jmp-jsl@octoplus-sa-claude-skills
```

## Available skills

| Plugin | What it does |
| ------ | ------------ |
| `jmp-jsl` | Write, debug, and review JMP Scripting Language (JSL) for SAS JMP 19. Ships with offline references generated from the JMP 19 PDFs. |

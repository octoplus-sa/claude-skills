Three-Dimensional Scenes
Scripting in Three Dimensions
JSL includes commands for scripting three-dimensional scenes derived from OpenGL.
Although not a complete OpenGL® implementation, JSL’s 3-D scene commands enable
complex, interactive plots to be constructed and viewed. The Surface Plot platform in JMP is
built using JSL scene commands.
